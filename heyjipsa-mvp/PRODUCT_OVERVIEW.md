# 헤이집사 (HEYJIPSA) — 제품 종합 설명서

> "집안일을 **인식**하고, 거기서 필요한 걸 **사는 것**까지 챙겨주는 AI 집사."
> 1인·맞벌이 가구를 위한 모바일 살림 비서 (MVP).

---

## 1. 한 줄 소개 & 비전

**헤이집사**는 흩어져 있는 집안일·장보기·소비·가계를 하나로 묶어,
"무엇을 해야 하고 → 무엇이 떨어졌고 → 무엇을 어디서 사야 가장 싼지"를
**자동으로 이어주는** 모바일 웹앱이다.

핵심은 단순 체크리스트 앱이 아니라 **파이프라인**이라는 점이다:

> **집안일/소비 인식 → 소비 주기 학습 → 다음 장보기 자동 구성 → 배송비 0원 묶음 추천**

이 한 줄이 제품의 정체성이며, 다른 살림 앱과의 차별점이다.

---

## 2. 문제의식 & 타깃 사용자

| 문제 | 헤이집사의 답 |
|---|---|
| 집안일이 머릿속에만 있고 자꾸 빠뜨린다 | 가구 유형별 **자동 생성 체크리스트** (주기별) |
| 생필품이 "떨어지고 나서야" 안다 | **소비 주기 학습 → 떨어지기 전에 미리 장바구니** |
| 장 볼 때마다 배송비가 아깝다 | **무료배송 기준 맞춰 플랫폼별 묶음 최적화** |
| 가사 분담이 늘 불공평하게 느껴진다 | 가사노동 **기록 → 분담 비율 시각화** |
| 돈이 어디 새는지 모른다 | 영수증 분류로 **생필품/사치품 지출 구조** 파악 |

**타깃**: 1인 자취, 2인 맞벌이, 어린 자녀 가구, 부모님 동거 가구 등
"시간은 없고 챙길 건 많은" 한국 가정.

## 3. 핵심 컨셉: 인식 → 구매 → 배송 파이프라인

```
[집안일/소비 인식]      [소비주기 학습]        [자동 장보기]         [배송 최적화]
 소모품 "사용" 체크   →   사용빈도+재구매주기  →  곧 떨어질 품목을   →  쿠팡 무료배송
 집안일 체크 연동        EWMA·이상치제거       「이번 주 장보기」     기준 묶음 추천
 영수증/구매 기록        신뢰도·수량보정        에 자동 추가          (절약액 계산)
```

이 네 단계가 **실제로 코드로 연결**되어 있다. 한 단계의 변화(예: 빨래를 자주
하면 세제 사용이 잦아짐)가 그다음 단계(세제가 더 빨리 장바구니에 담김)로
자동 전파된다. (자세한 동작은 5장)

## 4. 기능 전체 지도 (화면별)

앱은 **랜딩 → 온보딩 → 앱 셸(하단 6탭)** 구조다.

### 4.0 랜딩 / 온보딩
- **랜딩**: 크림색(#F6EEDA) 배경 중앙에 집사 로고, `시작하기` 버튼 하나로 미니멀.
- **온보딩 (3단계)**:
  1. 가구 유형 선택 (1인 / 2인 맞벌이 / 부부+아이 / 다자녀 / 부모님 동거)
  2. 옵션 (반려동물·식물·자동차·렌탈가전)
  3. 자동 생성된 체크리스트 **미리보기 → 불필요 항목 빼기 + 직접 추가**(텍스트·음성)

### 4.1 홈 (메인 대시보드) `/home`
오늘 챙길 것을 한 화면에:
- **이번 주 장보기** 카드 — 예상 금액 + "쿠팡에서 한 번에 주문하면 배송비 0원" 여부
- **소모품 자동 보충** 레이더 — 곧 떨어질 품목(D-day, 🔥 사용 급증 표시)
- **오늘의 집안일** 진행률
- **이번 달 고정비** D-day

### 4.2 장보기 `/shopping` (3탭)
- **이번 주 장보기**: 품목 관리(수량·예상가·브랜드/최저가 선호) + **배송비 최적화** 결과
  (플랫폼별 묶음, 무료배송 충족 여부, "따로 주문 대비 절약액"). 소모품 파이프라인이
  자동으로 담은 품목은 `자동` 배지로 구분.
- **구매 기록**: 영수증/주문내역을 **사진(OCR) 또는 텍스트**로 입력 → 누적
- **재구매 패턴**: 품목별 재구매 주기·다음 예상일(D-day), 월별 지출 차트, "곧 다시 살 때"

### 4.3 집안일 체크리스트 `/checklist` (4+2탭)
- **주기 탭**(오늘/이번 주/이번 달/계절): 가구 맞춤 항목 체크, 직접 추가(텍스트·음성),
  매일 항목은 날짜 바뀌면 자동 리셋
- **소모품 탭**: 스마트 소비주기 학습 + 집안일 연동 (5장에서 상세)
- **내 할일 탭**: 자연어로 적으면 카테고리·우선순위·기한 자동 분류

### 4.4 가사분담 `/chores`
- 누가 무엇을 얼마나 했는지 **자연어로 기록** ("어제 내가 설거지 20분")
- 구성원별 **분담 비율·시간 대시보드**(차트)로 공정성 가시화

### 4.5 가계관리 `/budget` (2탭)
- **장바구니 분석**: 영수증/장바구니 텍스트를 **생필품·준생필품·사치품**으로 자동 분류,
  지출 구조 시각화 (117개 키워드 DB 기반)
- **고정비**: 월세·관리비·구독 등 등록 → 납부일 **D-day** 관리

### 4.6 살림 팁 `/tips`
- 청소·빨래·요리·수납·생활꿀팁·절약 **60개 팁**을 키워드 검색

### 4.7 공통: 음성 & OCR
- **음성 입력 FAB**(🎤): 어느 화면에서나 말하면 할 일/기록을 자동 분류해 추가
- **OCR 버튼**(📷): 주문완료 스크린샷·마트 영수증을 인식해 품목·가격 추출

## 5. 차별화 포인트: 스마트 소모품 자동보충 (심화)

제품의 심장. "소비를 인식해서 미리 사주는" 부분을 실제로 구현한 모듈이다.

### 5.1 데이터 모델 (`Consumable`)
```ts
interface Consumable {
  name, category, cycleDays   // 기본 소비 주기(학습 전 fallback)
  lastBought, fills[]         // 보충 이력 (재구매 주기 학습)
  uses[]                      // 사용 이벤트 (사용빈도 학습)
  linkedChoreIds[]            // 연동 집안일 — 체크 시 '사용'으로 집계
  lowSince                    // "거의 다 썼어요" → 즉시 필요
}
```

### 5.2 학습 알고리즘 (`predictRestock`)
단순 평균이 아니라 다음을 결합한다:

1. **재구매 주기 추정**
   - 보충 이력 + 매칭되는 **구매 기록(영수증)** 을 한 타임라인으로 합침
   - **수량 보정**: 2팩 사면 ~2배 오래 감 → "1개당 소비 일수"로 환산
   - **이상치 제거**: 휴가·대량구매 등 비정상 간격을 중앙값 기준으로 트림
   - **최근 가중 평균(EWMA)**: 습관이 바뀌면 최근 주기를 더 신뢰
   - **신뢰도**: 간격의 변동계수(CV)로 높음/보통/낮음 산출

2. **사용 빈도 보정 (intensity)**
   - 연동된 집안일을 체크하면 그 소모품에 "사용 1건" 기록
   - **최근 사용 페이스 ÷ 평소 페이스**로 소진 속도를 보정
     (자주 쓰면 예상일을 앞당기고 🔥, 뜸하면 늦춤 🐢)

3. **적응형 알림 시점 (leadDays)**
   - 주기의 20%(2~10일) + 신뢰도가 낮을수록 여유
   - → 10일짜리 생수와 45일짜리 샴푸를 똑같이 D-7로 보지 않음

> **결과**: "이번 주 빨래를 많이 한 집은 세제가 더 빨리 떨어진다"를 앱이 학습해
> 떨어지기 전에 미리 장바구니에 담는다. (실측 검증: 어떤 품목은 *사용 빈도 때문에만*
> 자동 추가되며, 사용 기록을 빼면 추가되지 않음 → 사용빈도가 실제 동인임을 증명)

### 5.3 파이프라인 동기화 (`syncAutoRestock`)
- 곧 필요한(임계 이내/지남) 소모품을 **장보기에 자동 추가**, 더는 불필요한 자동
  항목은 **자동 제거** (여러 번 호출해도 안전한 idempotent 설계)
- 추가된 품목은 그대로 **배송비 최적화기**로 흘러가 쿠팡 무배 묶음까지 연결
- 실행 시점: 홈/장보기 진입, 소모품 액션, **연동 집안일 체크** 시

## 6. 기술 아키텍처

### 6.1 스택
| 영역 | 선택 |
|---|---|
| 빌드/번들 | **Vite 8** (rolldown) |
| UI | **React 19.2** + TypeScript ~6 |
| 스타일 | **Tailwind CSS v4** (`@tailwindcss/vite`, `@theme` 토큰) |
| 라우팅 | **react-router-dom 7**, `HashRouter` (정적 호스팅·네이티브 file:// 호환) |
| 상태/저장 | **React hooks + localStorage** (백엔드·DB 없음) |
| 차트 | **chart.js + react-chartjs-2** (도넛/막대/선) |
| OCR | **tesseract.js**(웹) + **ML Kit**(네이티브) |
| 음성 | **Web Speech API**(웹) + **@capacitor-community/speech-recognition**(네이티브) |
| 네이티브 | **Capacitor 8** (iOS/Android 래핑) |

### 6.2 앱 구조
- **라우팅**: `/`(랜딩), `/onboarding` 은 풀스크린. 나머지는 `Layout`(하단 네비 +
  온보딩 가드) 아래 `/home /shopping /checklist /chores /budget /tips`.
- **상태 관리**: 전역 스토어 없이, 각 페이지가 localStorage를 직접 읽고/쓰는 단순
  모델. 저장 키는 `STORAGE_KEYS`로 일원화(가구설정·장보기·체크상태·가사기록·고정비·
  예산·할일·구매기록·**소모품**).
- **렌더 패턴**: 파생 데이터는 렌더 시 계산(예: 체크리스트 산출, 배송 최적화),
  소모품 동기화는 진입 시 idempotent 호출.

### 6.3 데이터 출처 & "Python → TypeScript 충실 포팅" 철학
이 앱의 데이터·알고리즘은 새로 만든 게 아니라, 저장소에 있던 **10개의 Python
스킬**을 TypeScript로 **그대로 포팅**한 것이다. (한국어 데이터·로직 보존)

| 원본 Python 스킬 | 포팅된 TS 모듈 | 역할 |
|---|---|---|
| `household-checklist` | `utils/checklist.ts` + `data/templates.ts` | 가구 조건 → 주기별 체크리스트 산출 |
| `smart-cart-optimizer` | `utils/cartOptimizer.ts` + `data/platforms.ts` | 무료배송 기준 묶음 최적화 |
| `budget-guard` | `utils/budgetGuard.ts` + `data/budgetCategories.ts` | 생필품/사치품 분류 (키워드 117개) |
| `chore-logger` | `utils/choreParser.ts` | 가사노동 자연어 기록 파싱 |
| `chore-dashboard` | `utils/choreAnalytics.ts` | 분담 비율 분석 |
| `voice-to-todo` | `utils/todoParser.ts` | 자연어 → 할일(분류·우선순위·기한) |
| `purchase-pattern` | `utils/purchaseAnalyzer.ts` | 재구매 주기·지출 분석 |
| `receipt-scanner` | `utils/receipts.ts` | 구매 기록 스키마·검증 |
| `shipping-fee-filter` | `utils/shippingFilter.ts` | 배송비 필터(현재 UI 비노출) |
| `home-tips-qa` | `utils/tipSearch.ts` + `data/tips.ts` | 살림 팁 60개 검색 |

포팅 시 원본 CLI를 실제로 돌려 결과가 일치하는지 **교차 검증**했다.
(`consumables.ts`만 신규 — 위 조각들을 잇는 "허리".)

### 6.4 핵심 알고리즘 모듈 요약
- **`cartOptimizer`**: ① 태그/선호로 1차 배분 → ② 무배 기준 부족분을
  "작은 gap 우선" 그리디로 채움 → ③ 따로 주문 대비 절약액 계산.
- **`budgetGuard`**: 사치품 우선 순서로 키워드 매칭 분류(일반어 충돌 방지),
  카테고리별 지출 합산.
- **`purchaseAnalyzer`**: 품목명 정규화 → 그룹 → 평균 재구매 주기·다음 예상일,
  월별 지출, KPI.
- **`consumables`**: 5장의 스마트 학습 엔진.
- **`checklistState`**: 날짜 변경 감지 → "오늘" 항목만 자동 리셋(주/월/계절은 유지).

### 6.5 OCR / 음성 (이중 백엔드)
- **OCR**: 웹에서는 `tesseract.js`(WASM, 동적 import로 초기 번들 분리), 네이티브에서는
  카메라 + ML Kit. 인식 텍스트는 동일한 파서(`parseCart`)로 품목·가격 추출.
- **음성**: 웹은 `Web Speech API`(localhost·HTTPS 보안 컨텍스트에서 동작), 네이티브는
  Capacitor 플러그인. 지원 안 되면 버튼 자체를 숨김(`isVoiceSupported`).

### 6.6 디자인 시스템
- Tailwind v4 `@theme` 토큰 팔레트: **navy**(주색)·**blue**·**mint**(강조)·
  **cream/light**(배경)·**ink/muted**·**danger**.
- 진행률 바는 블루→민트 그라데이션, 카드 라운드 2xl, 모바일 퍼스트(390px 기준).
- 브랜딩: 사용자의 네이비 집사 아이콘을 크로마키 처리해 로고/앱아이콘으로 사용.

## 7. 네이티브 패키징 & 배포

- **Capacitor 8**로 동일한 웹 빌드(`dist`)를 iOS/Android 네이티브 셸에 래핑.
  `appId: com.heyjipsa.app`, `appName: 헤이집사`.
- **안드로이드**: 로컬 빌드 없이 **GitHub Actions**(`.github/workflows/android.yml`)로
  클라우드에서 디버그 APK를 빌드해 아티팩트로 다운로드(검증 완료, ~12.8MB).
- **iOS**: 무료 사이드로딩 불가 — Apple Developer($99) + Mac 또는 클라우드 빌드 →
  TestFlight(내부 테스터) 경로.
- **PC 웹 실행**: `start-heyjipsa.bat` 더블클릭 → `npm install` + dev 서버 →
  `localhost`라 **음성·OCR까지 전부 동작**. (폰 없이 전체 기능 검증 가능)

## 8. 데이터 & 프라이버시
- **백엔드·서버 전송 없음.** 모든 데이터(가구설정·기록·소모품 등)는 기기
  localStorage에만 저장된다.
- 사진(OCR)·음성은 인식 후 텍스트만 사용하며 외부로 업로드하지 않는다
  (웹 OCR/음성은 브라우저 내 처리, 네이티브는 온디바이스 ML Kit/STT).

## 9. 품질 보증 (검증 방식)
- **정적 검증**: `tsc -b`(엄격 옵션: `verbatimModuleSyntax`, `erasableSyntaxOnly`,
  `noUnusedLocals/Parameters`) + ESLint(typescript-eslint, react-hooks/react-compiler).
- **로직 테스트**: localStorage를 모킹해 파이프라인을 실제 실행하는 검증 스크립트
  (소모품 학습 17개 항목 등 통과).
- **렌더 검증**: 헤드리스 Chromium 스크린샷으로 온보딩→전 화면 무오류 렌더 확인.
- **포팅 정합성**: 원본 Python CLI 출력과 대조.

## 10. 한계 & 솔직한 경계 (MVP)
- **실제 주문/결제 자동화는 없음** — 배송비 최적화 후 **플랫폼 링크로 이동**까지가
  현실적 범위(쿠팡 등 제휴·API 필요).
- **단일 기기·단일 사용자** — 클라우드 동기화/계정 없음(localStorage).
- 가격은 **카테고리 중간값 추정** — 실시간 시세 연동 아님.
- 소비주기 학습은 데이터가 쌓일수록 정확해지는 **콜드스타트** 특성(초기엔 기본값+신뢰도 낮음).
